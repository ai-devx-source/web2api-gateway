# Домены провайдеров и диагностика (Web2API Gateway)

Этот файл содержит информацию о том, какие домены используются для авторизации и работы различных ИИ-моделей в нашем шлюзе. Эта информация будет полезна для дальнейшей диагностики, если изменятся интерфейсы или методы входа.

## 1. MiniMax (Hailuo AI)
У Minimax сложная система доменов из-за ребрендинга:
* **https://agent.minimax.io** — ✅ **РАБОЧИЙ ДОМЕН** (международный). Вход по Email/паролю через Clerk. Токен в localStorage по ключу `_token`.
* **https://hailuoai.video / https://www.hailuoai.com** — Новый глобальный домен (Hailuo AI). Только Google SSO / Apple SSO.
* **https://agent.minimaxi.com** — Китайский домен. Только телефон (Китай) и WeChat. Возвращает 401 для аккаунтов с agent.minimax.io.
* **https://platform.minimaxi.com** — Платформа разработчиков с официальными API Keys (`sk-...`).

**Текущая реализация (✅ работает):**
- Транспорт: **DOM Proxy** (Puppeteer + Stealth)
- Домен: `https://agent.minimax.io/mavis?id=<character_id>`
- Аутентификация: JWT токен инжектируется в `localStorage._token` перед навигацией
- Ввод: `document.execCommand('insertText')` для ProseMirror/Tiptap
- Ответ: парсится из `div.matrix-markdown.message-content`
- Скорость: ~15-20 секунд на запрос

**Как обновить токен:** `npm run minimax:auth` → вариант 2 (ручной ввод).
Токен берётся из браузера на `agent.minimax.io`: F12 → Application → Local Storage → ключ `_token`.

## 2. Qwen (Alibaba)
* **https://chat.qwenlm.ai** — Глобальный чат Qwen.
* **Диагностика:** Автоматический вход может блокироваться анти-фрод системами Alibaba. В программе реализован как автоматический вход через запуск браузера, так и ручной ввод токена. Токен хранится в Local Storage под ключом `token` (или извлекается из JWT/Cookies).

---

## 3. DeepSeek
* **https://chat.deepseek.com** — Официальный чат DeepSeek.
* **Диагностика:** Токен извлекается аналогичным образом. Провайдер использует внутренние токены (Bearer), которые можно скопировать из заголовков сетевых запросов (Network) или Local Storage.

---

## 4. Kimi (Moonshot)
* **https://kimi.moonshot.cn** — Чат Kimi.
* **Диагностика:** Используется токен доступа (обычно `refresh_token` и `access_token`). Токены можно получить после авторизации по номеру телефона в веб-интерфейсе.

## 5. Zai
* **https://zai.co** (или аналогичные домены платформы) — Чат Zai.
* **Диагностика:** Автоматический скрапер может собирать данные из DOM-дерева чата, если API недоступно.

## 6. Xiaomi 
* **https://account.xiaomi.com** — Единый аккаунт Xiaomi.
* *(В процессе интеграции)* — Для Xiaomi используются данные `admin@taskmind.ru` / `AI_DEVX_TEST`. Домен авторизации стандартный для экосистемы Xiaomi.

## Общие правила отладки токенов:
1. Зайти на нужный домен в обычном браузере (при необходимости включить VPN).
2. Авторизоваться (почта, телефон, Google SSO).
3. Нажать **F12** (Откроются инструменты разработчика).
4. Перейти во вкладку **Application** (Приложение) -> **Local Storage**.
5. Найти ключ `token` (или `access_token`), скопировать его значение.
6. Вставить токен через `npm run <провайдер>:auth` (или скрипты `addAccount.js`).
