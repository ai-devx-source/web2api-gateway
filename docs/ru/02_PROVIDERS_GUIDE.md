# 02. Настройка Провайдеров (Providers Guide)

Для того чтобы шлюз мог отправлять запросы в ту или иную нейросеть, вам необходимо добавить в него токены (cookie или заголовки) от ваших аккаунтов на соответствующих сайтах.

В `ApiConnector` встроены интерактивные CLI-скрипты для быстрого и безопасного добавления токенов.

---

## 1. DeepSeek

DeepSeek поддерживает как API-токены (Bearer), так и ручной перехват браузерных сессий (из-за защиты Cloudflare).

**Команда:**
```bash
npm run deepseek:auth
```

**Как получить токены:**
Скрипт откроет видимое окно браузера. Вам нужно авторизоваться на сайте [chat.deepseek.com](https://chat.deepseek.com/). После прохождения капчи и входа в аккаунт, вернитесь в терминал и нажмите `Enter`. Скрипт сам перехватит все нужные заголовки и куки.

---

## 2. Kimi (Moonshot)

Kimi работает через обход защиты Cloudflare (режим DOM-Proxy) или прямое API при наличии валидных токенов.

**Команда:**
```bash
npm run kimi:auth
```

**Как получить токены:**
Как и у DeepSeek, скрипт запустит браузер. Авторизуйтесь на сайте [kimi.moonshot.cn](https://kimi.moonshot.cn/), отправьте одно тестовое сообщение в чат и нажмите `Enter` в консоли.

---

## 3. MiniMax

MiniMax (Hailuo AI) работает по схожему принципу, перехватывая заголовки из официального веб-приложения.

**Команда:**
```bash
npm run minimax:auth
```

**Как получить токены:**
Авторизуйтесь в открывшемся окне браузера на сайте [hailuoai.video](https://hailuoai.video) или соответствующем чате MiniMax. Отправьте запрос, вернитесь в консоль и нажмите `Enter`.

## 6. Perplexity AI

Perplexity требует ручного копирования Cookie-файла сессии из-за сложной системы защиты Cloudflare Turnstile.

**Команда:**
```bash
npm run perplexity:auth
```

**Как получить токены:**
1. Зайдите на [www.perplexity.ai](https://www.perplexity.ai) в вашем обычном браузере и авторизуйтесь.
2. Нажмите `F12` (Инструменты разработчика) -> вкладка `Application` (или `Storage`) -> `Cookies`.
3. Найдите cookie с названием `__Secure-next-auth.session-token` и скопируйте его значение.
4. Вставьте это значение в запущенный скрипт терминала.

---

## 7. Xiaomi MIMO

MIMO требует копирования трех различных параметров cookie.

**Команда:**
```bash
npm run mimo:auth
```

**Как получить токены:**
1. Зайдите на [aistudio.xiaomimimo.com](https://aistudio.xiaomimimo.com) и авторизуйтесь.
2. В консоли разработчика (`F12`) скопируйте значения следующих Cookie:
   - `serviceToken`
   - `userId`
   - `xiaomichatbot_ph`
3. Вставьте их по очереди в терминал.

---

## 8. HuggingFace

Позволяет использовать бесплатные модели HuggingFace Chat (например, Llama 3, Mistral, Command R+).

**Команда:**
```bash
npm run hf:auth
```

**Как получить токены:**
1. Авторизуйтесь на [huggingface.co/chat](https://huggingface.co/chat).
2. Скопируйте Cookie `hf-chat` из консоли разработчика.
3. Вставьте значение в скрипт терминала.
