# 01. Быстрый Старт (Quickstart)

Добро пожаловать в **ApiConnector (Web2API Gateway)** — универсальный шлюз, который объединяет веб-интерфейсы множества различных нейросетей в единый OpenAI-совместимый API эндпоинт.

## Поддерживаемые Провайдеры

На данный момент шлюз поддерживает 8 провайдеров:
1. **Qwen (Tongyi Qianwen)**
2. **Z.ai / GLM**
3. **DeepSeek**
4. **Kimi (Moonshot)**
5. **MiniMax**
6. **Perplexity AI**
7. **Xiaomi MIMO**
8. **HuggingFace**

## Системные требования

- **Node.js** версии 18 или выше.
- **Google Chrome** для провайдеров, требующих решения Cloudflare или DOM-проксирования (Kimi, DeepSeek).

## 🛠️ Установка и запуск (Максимально просто!)

Вам больше не нужно вводить сложные команды в терминале. Мы подготовили автоматические скрипты!

1. **Установка (Первый запуск):**
   - **Для Windows:** Просто кликните два раза по файлу `web2api-install.bat`. Он сам скачает все зависимости (`npm install`) и настроит проект.
   - **Для Linux / Mac:** Запустите `./web2api-install.sh`.

2. **Ежедневный запуск:**
   - **Для Windows:** Кликните два раза по `web2api-start.bat`.
   - **Для Linux / Mac:** Запустите `./web2api-start.sh`.

После этого откроется **Интерактивное CLI меню**! В нем вы можете отслеживать статусы провайдеров, авторизовывать аккаунты, менять активный профиль и управлять настройками.

*(Для продвинутых пользователей: вы по-прежнему можете использовать стандартные `npm install` и `npm start`)*



## Использование API

По умолчанию сервер запускается на порту `3000`. Ваш базовый URL для любых совместимых клиентов:
`http://localhost:3000/v1`

Ключ API (`Bearer Token`): `sk-any-string-you-want` (может быть любым, если не настроена строгая аутентификация в `.env`).

### Пример запроса:

```bash
curl http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-12345" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "Привет! Как дела?"}],
    "stream": true
  }'
```

Шлюз **автоматически** определит провайдера по имени модели (`deepseek-chat` -> DeepSeek). Если модель не распознана, запрос будет отправлен *Провайдеру по умолчанию*, который выбран в пункте 9 CLI-меню.

Переходите к [02_PROVIDERS_GUIDE.md](./02_PROVIDERS_GUIDE.md) для настройки аккаунтов и токенов.
