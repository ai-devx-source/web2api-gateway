# 04. Генерация изображений (Image Generation)

Помимо текстовых чатов, `ApiConnector` поддерживает генерацию изображений по стандарту OpenAI API (`/v1/images/generations`). 
В данный момент эта функция реализована через интеграцию с **Alibaba Cloud DashScope**, что позволяет использовать мощные модели от Qwen и Wan.

## Настройка

Для генерации изображений вам потребуется получить API-ключ от платформы DashScope (Aliyun).

1. Перейдите на консоль DashScope и получите API-ключ.
2. В корневой папке проекта откройте файл `.env`.
3. Добавьте или обновите следующую строку:
   ```env
   DASHSCOPE_API_KEY=your-dashscope-api-key-here
   ```
4. Перезапустите сервер `ApiConnector`.

## Поддерживаемые Модели

На данный момент модуль генерации поддерживает следующие модели:

- `qwen-image-max`
- `qwen-image-plus` (Используется по умолчанию, если модель не указана)
- `qwen-image`
- `wan2.6-t2i`
- `wan2.5-t2i-preview`
- `wan2.2-t2i-flash`

> [!TIP]
> Модели серии **Wan** используют асинхронную генерацию. Шлюз `ApiConnector` автоматически берет на себя ответственность за пуллинг (polling) статуса задачи, поэтому для клиента процесс выглядит как обычный синхронный HTTP запрос.

## Использование через API

Вы можете генерировать картинки с помощью стандартных HTTP-запросов, совместимых с OpenAI SDK:

```bash
curl -X POST http://localhost:3000/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-12345" \
  -d '{
    "model": "qwen-image-plus",
    "prompt": "Футуристичный город на Марсе с неоновой подсветкой, киберпанк",
    "n": 1,
    "size": "1024x1024"
  }'
```

**Дополнительные (нестандартные) параметры**:
Помимо стандартных параметров OpenAI, вы можете передавать:
- `negativePrompt` (строка) — Что НЕ должно присутствовать на изображении.
- `promptExtend` (boolean) — Разрешить ли ИИ автоматически расширить и улучшить ваш промпт (по умолчанию `true`).
- `watermark` (boolean) — Добавлять ли водяной знак (по умолчанию `false`).

Эти параметры можно передать в поле `options`, если вы работаете напрямую, или через `extra_body` в OpenAI SDK.
